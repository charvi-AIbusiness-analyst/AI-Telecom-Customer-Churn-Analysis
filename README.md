# 📊 AI Telecom Customer Churn Analysis

## 📌 Project Overview

This project analyzes customer churn in a telecom company using Business Analysis, SQL, Power BI, and AI.

The objective is to identify customers who are likely to leave and recommend strategies to improve customer retention.

---

## 🎯 Business Problem

Telecom companies lose revenue when customers discontinue their services.

This project identifies churn drivers and provides actionable recommendations to reduce customer churn.
